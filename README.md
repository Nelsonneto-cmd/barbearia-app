# ✂️ Barbearia App

Aplicação web para uma barbearia, onde o cliente pode ver os serviços e marcar o seu corte online.

## Funcionalidades

- Página inicial com apresentação da barbearia
- Lista de serviços com preços e duração
- Formulário de marcação (serviço, barbeiro, data e hora)
- Navegação entre páginas com React Router

## Tecnologias

- React
- Vite
- React Router
- CSS

## Como correr o projeto

```bash
git clone https://github.com/Nelsonneto-cmd/barbearia-app.git
cd barbearia-app
npm install
npm run dev
```
